    Interface IExpandedDefinition

    The definition with every value as it is (what expand gives): each slot whole, each tween's values at every position, and the drawings in each symbol. Published content has no root of its own: the HTML template merely instantiates one of the symbols. Every symbol in lib is extracted on an equal footing; which one to use as a root is up to the consumer.
