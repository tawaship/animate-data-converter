    Interface IDefinition

    The definition as extracted: the expanded definition with nothing left out but each value written once (expand gives the expanded form back exactly). Published content has no root of its own: the HTML template merely instantiates one of the symbols. Every symbol in lib is extracted on an equal footing; which one to use as a root is up to the consumer.
