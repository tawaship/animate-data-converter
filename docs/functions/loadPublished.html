    Function loadPublished

    • loadPublished(options: ILoadOptions): ILoadedContent

      Runs createjs (CreateJS 1.0.0, see CREATEJS_MODULE) and the published code in a fresh vm context and wires up the assets the way the HTML template does, without loading anything: every manifest entry gets a stand-in image (its src is the entry's path), and every sprite sheet of lib.ssMetadata is built over the manifest image of the same id. MotionGuidePlugin is installed, as the template does for content with motion guides.
